# NoSQL Injection

---

## 📌 Définition
> **NoSQL Injection** is a vulnerability where an attacker can manipulate NoSQL queries (such as MongoDB queries) by injecting malicious input, often due to improper input validation or unsafe query construction.

---

## 🛠️ Impact
- Authentication bypass (e.g. login bypass using query operators)
- Unauthorized access to database records
- Data extraction through query manipulation
- Modification or deletion of database content (depending on permissions)
