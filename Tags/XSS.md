# XSS - Cross-Site Scripting

---

## 📌 Définition
> **XSS (Cross-Site Scripting)** is a vulnerability where an attacker can inject malicious JavaScript into a web application, causing it to execute in the victim’s browser.

---

## 🛠️ Impact
- Stealing session cookies (session hijacking)
- Performing actions as the victim user (account takeover)
- Defacing or modifying page content in the victim’s browser
- Phishing attacks by injecting fake login forms
