# SMB - Server Message Block

---

## 📌 Définition
> **SMB (Server Message Block)** is a network protocol used for file sharing, printer sharing, and communication between computers on a local network, commonly found on Windows environments.

---

## 🛠️ Impact
- Unauthorized access to shared files and directories
- Disclosure of sensitive information (configs, credentials, backups)
- User enumeration and domain information gathering
- Lateral movement opportunities in Windows/Active Directory environments
