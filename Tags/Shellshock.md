# Shellshock

---

## 📌 Définition
> **Shellshock** is a vulnerability in the Bash shell where an attacker can execute arbitrary commands by injecting malicious environment variables, often through CGI scripts or services that pass user input to Bash.

---

## 🛠️ Impact
- Remote Code Execution (RCE) on the target system
- Full server compromise if the service runs with high privileges
- Data theft or system modification through arbitrary command execution
