# CMS - Content Management System

---

## 📌 Définition
> **CMS (Content Management System)** is a web application used to manage website content (posts, pages, media, users). Vulnerabilities in CMS platforms often come from outdated versions, weak credentials, insecure plugins, or misconfigured admin panels.

---

## 🛠️ Impact
- Authentication bypass or admin panel compromise
- Remote Code Execution through vulnerable plugins/modules
- Disclosure of sensitive configuration files and database credentials
- Full website compromise and potential server access
