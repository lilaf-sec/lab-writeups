# Command Injection

---

## 📌 Définition
> **Command Injection** is a vulnerability where user input is passed unsanitized to a system shell, allowing an attacker to execute arbitrary operating system commands on the server.

---

## 🛠️ Impact
- Remote code execution with the privileges of the web application
- Reverse shell and initial foothold on the server
- Reading or modifying sensitive files on the system
- Pivoting to internal services and further privilege escalation
