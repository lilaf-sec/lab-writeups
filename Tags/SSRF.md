# SSRF - Server Side Request Forgery

---

## 📌 Définition
> **SSRF (Server-Side Request Forgery)** is a vulnerability where an attacker can force a server to make requests to internal or external resources, potentially leading to data leaks or remote exploitation.

---

## 🛠️ Impact
- Access internal services (localhost, internal IPs)
- Cloud metadata leaks (AWS, Azure, GCP)
- Port scanning internal network
